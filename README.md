
# Liberty File Parser 🧩

A **lightweight, browser-based Liberty (.lib) file parser** that helps you inspect, filter, and analyze standard-cell libraries with ease.

---

## ✨ Features

- **Zero-Setup**: Runs entirely in the browser—no server or installation required.
- **Interactive Filtering**: Filter cells by name, pin name, or leakage power threshold.
- **Rich Visualization**: View cell areas, leakage power, pin directions, timing arcs, and more.
- **Raw Data Access**: Inspect the full parsed structure for debugging or scripting.
- **Sample Library**: Instantly load a demo `.lib` to test-drive the tool.
